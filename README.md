# ENT303 Master Hub — PWA

Đây là bản PWA của file học ENT303.

## Cài như app
1. Đưa toàn bộ thư mục này lên một hosting HTTPS (ví dụ GitHub Pages, Netlify hoặc Cloudflare Pages).
2. Mở trang bằng Chrome/Edge/Safari.
3. Điện thoại: chọn **Add to Home Screen / Thêm vào Màn hình chính**.
4. Máy tính: Chrome/Edge thường hiện nút **Cài app** hoặc menu **Install app**.
5. Sau khi cài, app mở ở chế độ riêng như một ứng dụng.

## Lưu ý
- Không mở trực tiếp bằng `file://` nếu muốn PWA/service worker hoạt động.
- Dữ liệu học do app hiện tại lưu bằng LocalStorage, nên dữ liệu vẫn phụ thuộc trình duyệt/thiết bị. PWA không tự đồng bộ dữ liệu giữa điện thoại và máy tính.
